# LinkedIn 접근·관리

## 목적과 표현

경력 검색 노출·네트워킹과 국내외 기회 탐색을 위한 보조 채널로 운영한다. 우선 기본 프로필을 완성하고 새 성과가 있을 때 갱신한다. 게시물 작성이나 인맥 확대는 별도 요청이 있을 때 진행한다.

헤드라인은 핵심 직무와 기술, 소개는 전문 영역·대표 경험·일하는 방식을 짧게 전달한다. 웹·모바일·IoT 경험을 모두 나열하기보다 지원하려는 역할을 먼저 보여준다. 희망 직무는 과거 회사의 실제 직책과 구분한다.

## 접근

- 시작점: [LinkedIn](https://www.linkedin.com/).
- Ego Lite의 로그인된 계정에서 본인 프로필을 확인한다. 이름이나 검색 결과만으로 타인 프로필을 편집 대상으로 잡지 않는다.
- 헤드라인·소개·경력·학력·스킬·추천 콘텐츠와 구직 설정의 현재 화면을 확인한다.
- 한국어·영어 또는 추가 언어 프로필이 있으면 어떤 프로필을 수정하는지 먼저 확인한다. 영문 이름·직책·회사 공식 명칭은 확인값을 사용한다.

## 사이트 URL·로그인 방식

| 용도 | URL·진입 경로 |
|---|---|
| 공식 사이트 | [www.linkedin.com](https://www.linkedin.com/) |
| 로그인 | [LinkedIn 로그인](https://www.linkedin.com/login) |
| 본인 프로필 | 로그인 후 Me / 나 → View profile / 프로필 보기. 개인 프로필 URL은 공개 문서에 저장하지 않음 |
| 공고·지원 | 로그인 후 Jobs / 채용공고 메뉴에서 진입 |
| 구직 설정 도움말 | [Open to Work 안내](https://www.linkedin.com/help/linkedin/answer/a507508) |

- 기본 방식: 기존 Ego Lite 세션을 재사용한다. 세션이 없으면 공식 로그인 화면에서 **Google로 로그인**을 선택하고 기존 연결 계정을 사용한다.
- [공식 로그인 화면](https://www.linkedin.com/login)에서 **이메일 또는 전화번호·비밀번호** 입력과 **Apple 로그인·패스키** 선택지를 확인했다. 계정·환경별 표시 방식은 실제 화면에서 재확인한다.
- 사용자 계정에 이미 연결된 수단을 사용한다. 패스키·추가 인증·이메일 로그인 링크가 요청되면 사용자에게 넘긴다.
- 로그인 완료 후 본인 프로필로 이동해 이름·현재 회사·기존 경력이 맞는지 확인한다. 동명이인 검색 결과를 로그인 확인으로 사용하지 않는다.
- 사용자 계정의 실제 로그인 수단: **Google 계정**. 2026-10-01 사용자 직접 확인. 현재 세션 상태와 Google 인증 절차 자체는 직접 검증하지 않았다.
- 확인일: 2026-10-01. 방식은 공식 로그인 페이지의 공개 조회 결과 기준이며 실제 로그인 성공은 확인하지 않았다.

## 공개 범위와 구직 설정

[공식 Open to Work 안내](https://www.linkedin.com/help/linkedin/answer/a507508)에 따르면 전체 회원 공개와 채용 담당자 전용 등 노출 옵션이 있다. 채용 담당자 전용도 현재 회사에 대한 완전한 비공개를 보장하지 않는다. 이 설정은 본문 수정과 구분해 사용자가 원하는 범위를 확인한 뒤 변경한다.

공개 프로필에 PDF를 올리는 것과 특정 지원에 PDF를 제출하는 것은 공개 대상이 다르다. 연락처가 포함된 파일을 추천 콘텐츠에 올리기 전에 공개용 자료인지 확인한다. 기존 게시물·네트워크 알림 설정도 현재 화면에서 확인한다.

## 반영·검증 절차

1. 본인 프로필·사용 언어·기존 공개 범위를 확인한다.
2. 승인된 헤드라인·소개·경력 문안을 섹션별로 저장한다.
3. 새로고침 후 수정 섹션과 날짜·링크를 확인하고 실제 화면을 읽는다.
4. 언어별 프로필을 수정했다면 각각의 표현을 확인한다. 공개 미리보기를 사용할 수 있으면 대상 화면과 노출 범위를 확인한다.
5. 구직 설정을 변경한 경우 선택한 값이 유지되는지 별도로 확인한다.

## 연락·지원 관리

채용 메시지는 회사·포지션·조건·질문을 요약한다. 답장·InMail·인맥 요청·게시물·댓글은 각각 승인된 범위에서 실행한다. 공고 지원은 간편 지원과 외부 지원 경로를 구분하고 실제 제출 상태를 확인한다.

## 현재 상태와 남은 작업

2026-10-01 로그인된 한국어 본인 프로필에서 젠테라 경력을 추가하고 아틀로 종료월(2026.04), 레니프 종료월(2024.10), 시스네트정보 입사월(2017.07)을 정정했다. 네 회사에 최신 원고의 성과 전체를 입력했고 소개와 포트폴리오 링크를 갱신했다. 새로고침 후 경력·소개 유지와 실제 경력 화면을 확인했다.

변경 시 인맥 알림을 껐으며 저장 후 이직 공유 게시물과 인맥 추천은 건너뛰었다. 구직 공개 설정은 변경하지 않았다. 기존 로그인 세션을 사용했고 Google 인증 자체는 새로 수행하지 않았다.

2026-10-01~02 후속 사용자 승인으로 최신 PDF를 지원용 이력서 관리 화면에 업로드했다. 재접속 후 파일명·업로드 날짜를 확인했고 이력서 공유는 해제 상태를 유지했다. 공개 추천 콘텐츠에 PDF를 올린 것은 아니다.

2026-10-02 소개에 기존 기술 목록과 새 소개가 붙은 중복을 제거했다. 헤드라인은 `소프트웨어 엔지니어 · 개발 차장 | React · TypeScript · React Native | 젠테라`로 저장했다. 코트디부아르 교육은 프로젝트 항목에 정확한 현지 교육 기간과 제작·TOT 설명으로 반영했다. IoT지식능력검정은 확인된 기관·취득월로 자격증 항목에 추가했다. 저장 후 재접속과 실제 화면을 확인했다.

2026-10-02 사용자 확인에 따라 정보처리기사(2018.11)·웹디자인기능사(2017.06)·컴퓨터그래픽스운용기능사(2017.04)의 발행기관을 한국산업인력공단으로 기준 문서에 기록한 뒤 추가했다. 자격증 목록에 재진입해 기존 IoT 자격증을 포함한 네 항목의 명칭·취득월·기관을 확인하고 실제 화면을 읽었다. 공유 게시물 안내는 건너뛰었다. 추가 언어 프로필은 검증 범위에 포함하지 않았다.

2026-10-02 최종 대조에서 남아 있던 `Computer Engineering` 전공을 기준 문서의 `컴퓨터 소프트웨어`로 정정했다. 공유 안내를 건너뛰고 학력 목록에 재진입해 학사 네 항목·기간·전공 유지와 실제 화면을 확인했다.
