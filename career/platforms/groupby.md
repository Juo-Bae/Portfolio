# 그룹바이 접근·관리

## 목적과 표현

스타트업 제품 개발 포지션을 탐색하는 보조 채널로 운영한다. [공식 사이트](https://groupby.kr/)는 스타트업 채용공고와 직무·기술·회사 검색을 제공한다.

웹·모바일·IoT를 연결한 제품 개발, 요구사항을 기능으로 만든 경험, 팀 리딩과 제조 협업을 강조한다. 작은 팀에서 수행한 구체적인 작업 범위를 보여주되 혼자 전부 개발했다는 표현은 확인된 경우에만 사용한다.

## 접근

- 시작점: [그룹바이](https://groupby.kr/).
- Ego Lite의 본인 계정에서 프로필·이력서와 관심 공고에 접근한다.
- 첫 작업에서 가입·로그인 상태, 프로필 필드, PDF·링크 입력, 공고별 지원 경로를 확인한다.
- 플랫폼 내 제출인지 외부 채용 사이트 이동인지 공고마다 확인한다. 외부 사이트로 이동하면 계정·추가 문항·제출 자료를 다시 확인한다.

## 사이트 URL·로그인 방식

| 용도 | URL·진입 경로 |
|---|---|
| 공식 사이트·채용 탐색 | [groupby.kr](https://groupby.kr/) |
| 로그인 진입 | 공식 사이트의 로그인 버튼 또는 로그인 안내에서 진입 |
| 확인된 로그인 안내 | 공식 사이트의 “카카오로 3초만에 로그인하기” |
| 본인 프로필·지원 현황 | 로그인 후 메뉴에서 진입. 직접 URL은 현재 미확인 |
| 별도 로그인 페이지 URL | 미확인. 추정한 `/login` 경로를 운영 주소로 등록하지 않음 |

- 기본 방식: 기존 Ego Lite 로그인 세션을 재사용한다. 세션이 없으면 공식 사이트에서 로그인 안내를 열고 **카카오 로그인**을 선택한다.
- [공식 사이트 공개 검색 결과](https://groupby.kr/)에서 **카카오 로그인** 안내를 확인했다. 카카오가 유일한 로그인 방식인지는 확인하지 않았다.
- 사용자 계정에는 **카카오 2차 인증**이 있다. 세션이 만료됐거나 카카오 인증이 요청되면 사용자에게 브라우저 제어를 넘겨 로그인·2차 인증을 완료하도록 한다. 사용자가 제어를 돌려준 뒤 같은 작업 공간에서 그룹바이 복귀와 본인 프로필을 확인한다. 인증 완료 전에는 후속 계정 작업을 진행하지 않는다.
- 로그인 후 본인 프로필·기존 자료가 연결됐는지 확인한다. 다른 소셜 계정으로 신규 프로필을 만들지 않는다.
- 사용자 계정의 실제 로그인 수단: **카카오 계정·2차 인증 사용**. 2026-10-01 사용자 직접 확인. 현재 세션 상태와 인증 절차 자체는 직접 검증하지 않았다. 지원 방식 목록과 인증 복귀 URL은 계정 화면에서 추가 확인한다.
- 확인일: 2026-10-01. 카카오 로그인 안내는 공식 공개 검색 결과 기준이다.

## 관리 항목

| 항목 | 작성·갱신 기준 |
|---|---|
| 소개 | 제품 구현과 운영 적용 경험을 간결하게 제시 |
| 경력 | 회사별 기간·역할·직접 작업과 협업 범위를 명확히 작성 |
| 대표 사례 | 서비스·IoT 제품·운영 도구 중 공고와 관련 있는 사례 우선 |
| 개인 프로젝트 | ciRRus 등에서 확인된 구현 결과와 개발 경험을 제시. 사업 지표로 확대하지 않음 |
| 기술·희망 직무 | 실제 역량과 사용자 희망 조건에 맞게 선택 |
| 자료·링크 | 제공 필드가 지원하는 범위에서 최신 PDF와 포트폴리오 연결 |

자료: [공통 운영 기준](README.md), [사실 기준](../facts/README.md), [최신 이력서](../releases/resume/latest/resume.md), [프로젝트 자료](../../src/portfolioData.js).

## 반영·검증 절차

1. 실제 프로필 필드와 기존 자료를 읽어 지원되는 항목을 확인한다.
2. 승인된 문안·파일을 반영하고 저장한다. 없는 필드를 있다고 가정해 자동화하지 않는다.
3. 새로고침·프로필 미리보기에서 저장 여부와 링크·파일을 확인한다.
4. 대표 프로젝트 설명을 실제 화면에서 읽고 담당 범위·결과가 명확한지 확인한다.

## 공고·지원 관리

개발자의 담당 범위, 팀 구성, 제품·서비스 단계, 필수 역량, 근무 조건을 공고에서 확인한다. 팀 규모나 투자 단계만으로 고용 안정성·성장 가능성을 단정하지 않는다. 업무 범위가 넓으면 기대 역할과 개발 협업 환경을 확인할 질문으로 남긴다.

사용자가 승인한 공고에만 지원한다. 제출 경로가 외부라면 어느 사이트에 어떤 자료를 제출했는지 기록한다. 접수 확인 수단이 없으면 제출 여부를 미확인으로 남긴다.

## 현재 상태와 남은 작업

2026-10-01 로그인된 본인 프로필에서 다음을 저장하고 새로고침 후 확인했다.

- 회사 네 곳의 확정된 재직 기간과 최신 원고의 성과 전체. 젠테라·아틀로 추가, 시스네트정보 종료월 정정, 레니프 직책·리딩 반영.
- 경력 연차 7년, 최신 자기소개, ciRRus Layer의 Electron·React 기반 기능과 개인 프로젝트 설명.
- 코트디부아르 교육 활동(정확한 기간은 제목·본문, 날짜 필드는 2026.02), 자격증 네 개와 취득월.
- 프로필 공개는 꺼진 상태를 유지했다. 기존 로그인 세션을 사용했고 카카오 인증 자체를 새로 수행하지 않았다.

2026-10-01~02 사용자 구체 승인 후 최신 PDF를 업로드하고 새로고침·실제 화면으로 첨부를 확인했다. 세종사이버대학교의 `컴퓨터공학` 표기를 기준 문서의 `컴퓨터 소프트웨어`로 정정했다. 두 대학의 학사 졸업은 사용자 확인값이다.

아이윌·출석체크의 기존 사용자 수·기여율은 사용자 요청으로 유지했다. 유지 요청이 수치의 근거를 새로 검증했다는 뜻은 아니다. 저장 후 프로필 공개가 켜진 화면을 확인해 작업 시작 시의 비공개로 복원했으며 새로고침 후 비공개와 첨부 유지 여부를 확인했다. 적극 구직 상태 변경 제안은 거절했다. 공개 상태가 켜진 원인은 확인하지 못했다.

계정 프로필 진입점은 [프로필 관리](https://groupby.kr/scouts/my-profile)에서 직접 확인했다. 전체 플랫폼 누적 최종 검증은 별도다.
