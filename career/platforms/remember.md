# 리멤버 접근·관리

## 목적과 표현

경력직 스카우트·헤드헌터 제안을 받는 주요 채널로 운영한다. 직접 지원도 함께 관리한다. 이 서비스의 제안·지원 기능은 [공식 도움말](https://support.rememberapp.co.kr/hc/ko)에서 확인할 수 있다.

소개는 웹·모바일·IoT 제품 개발, 개발팀 리딩, 실제 사용 환경에 적용한 경험을 중심으로 쓴다. 경력 본문은 담당 작업과 결과를 구체적으로 유지한다. 직책만으로 기여율·의사결정 범위를 확대하지 않는다.

## 접근

- 시작점: [본인 프로필](https://profile.rememberapp.co.kr/).
- Ego Lite의 기존 리멤버 탭을 재사용한다. 로그인 계정과 본인 프로필을 확인한 뒤 편집한다.
- 내 프로필, 받은 제안, 지원 현황, 첨부 파일 관리에 각각 접근한다. 메뉴명은 작업 시 화면에서 확인한다.
- 프로필 공개 정보와 채용 서비스 전용 정보를 구분한다. 현재 공개 범위는 보존한다.

## 사이트 URL·로그인 방식

| 용도 | URL·진입 경로 |
|---|---|
| 공식 사이트 | [rememberapp.co.kr](https://rememberapp.co.kr/) |
| 로그인 | [로그인 화면](https://rememberapp.co.kr/login) |
| 프로필 관리 | [profile.rememberapp.co.kr](https://profile.rememberapp.co.kr/) |
| 채용공고 | [career.rememberapp.co.kr](https://career.rememberapp.co.kr/) |
| 도움말 | [공식 고객센터](https://support.rememberapp.co.kr/hc/ko) |

- 기본 방식: Ego Lite에 유지된 기존 로그인 세션으로 프로필 관리 URL에 접근한다.
- 세션이 없으면 공식 로그인 화면에서 **Google로 로그인**을 선택하고 기존에 연결한 Google 계정을 사용한다. [공식 로그인 화면](https://rememberapp.co.kr/login?redirect=https%3A%2F%2Frememberapp.co.kr%2F%23)의 공개 검색 결과에서 **리멤버 앱으로 로그인·이메일로 로그인**을 확인했다. 추가 소셜 방식은 아이콘만으로 이름을 추정하지 않는다.
- 로그인 완료 후 프로필 관리 URL로 이동해 본인 이름과 경력을 확인한다. 로그인 URL의 `redirect`는 목표 화면으로 복귀하기 위한 값이며 새 로그인 때 사이트가 생성하는 경로를 우선 사용한다.
- 앱 인증·추가 인증이 나오면 사용자에게 넘긴다. 기존 세션에서 프로필을 수정한 사실만으로 최초 로그인 수단을 확정하지 않는다.
- 사용자 계정의 실제 로그인 수단: **Google 계정**. 2026-10-01 사용자 직접 확인(“리멤버는 구글 로그인이야”). 로그인된 본인 프로필의 접근·수정은 이전 작업에서 확인했으며, Google 인증 절차 자체는 직접 검증하지 않았다.
- 확인일: 2026-10-01. 로그인 방식은 공식 공개 화면 검색 결과 기준이며, 실제 인증 절차는 계정 화면에서 재확인한다.

## 반영·검증 절차

1. 수정할 섹션과 현재 내용을 읽고 차이를 확인한다.
2. 승인된 내용을 입력한다. 긴 경력 항목은 일부 문장만 남거나 요약되는지 확인한다.
3. 완료 버튼으로 저장하고 프로필로 돌아온 것을 확인한다.
4. 새로고침 후 수정 문장·기간이 남아 있는지 확인한다. 첨부 파일은 파일 관리에서 별도로 확인한다.
5. 변경된 영역을 실제 화면에서 읽어 잘림·누락·중복이 없는지 확인한다.

## 제안·지원 관리

제안을 읽고 회사·직무·업무 범위·근무 조건·확인할 질문을 요약한다. 수락·거절·답장은 사용자 승인 범위에서 수행한다. 직접 지원 시 같은 회사·포지션의 기존 지원을 먼저 확인한다.

## 현재 상태와 다음 점검

2026-10-01 본인 프로필의 소개·네 회사 경력·학력 4건·자격증 4건·스킬 15개·포트폴리오 URL·코트디부아르 강의 날짜가 최신 기준과 맞는지 대조했다. 첨부 관리자에는 `soonho-bae-resume.pdf` 한 개가 표시됐으나 이번 대조에서 파일을 다시 다운로드해 비교하지는 않았다.

후속 수정에서 소개 마지막의 `개발 했습니다`를 `개발했습니다.`로 고치고 저장·새로고침 후 확인했다. 그 외 사용자 문안은 보존했다.

다음 갱신에서는 재직 상태·총 경력의 기준일, 제출 PDF, 새로 추가된 성과를 우선 대조한다. 과거에 확인한 UI 제한과 메뉴는 고정 계약으로 취급하지 않는다.
