# 구직 플랫폼 운영 기준

작성일: 2026-10-01. 이 문서는 플랫폼별 접근·관리 절차를 정의한다. 외부 프로필을 수정하거나 지원을 실행하는 승인, 자동 실행 스케줄은 포함하지 않는다.

## 플랫폼별 역할

아래 역할과 우선순위는 현재 경력을 기준으로 정한 운영 방침이다. 플랫폼 전체의 채용 성과를 보장하는 평가가 아니다.

| 플랫폼 | 역할 | 관리 우선순위 | 개별 문서 |
|---|---|---|---|
| 리멤버 | 경력직 스카우트·헤드헌터 제안과 직접 지원 | 주요 채널 | [리멤버](remember.md) |
| 원티드 | 웹·모바일 개발 직무 지원과 면접 제안 | 주요 채널 | [원티드](wanted.md) |
| 그룹바이 | 스타트업의 제품 개발 포지션 탐색·지원 | 보조 채널 | [그룹바이](groupby.md) |
| LinkedIn | 경력 검색 노출·네트워킹과 국내외 기회 탐색 | 기본 프로필 유지 | [LinkedIn](linkedin.md) |

## 기준 자료와 문안

1. [경력 자료 안내](../README.md), [경력·학력·자격증 기준](../facts/README.md)을 먼저 읽는다.
2. 제출용 원고·PDF는 [최신 이력서](../releases/resume/latest/resume.md)를 사용한다. 웹 제공 PDF도 같은 최신 파일인지 확인한다.
3. 프로젝트는 [웹 표시 데이터](../../src/portfolioData.js)의 확인된 작업 범위를 참고한다. [교육 활동 기간](../facts/education-activities.md)도 대조한다.
4. 모든 플랫폼에서 이름·재직 기간·직책·학력·자격증·성과의 사실관계를 일치시킨다. 강조 순서와 분량은 직무에 맞게 달리한다.
5. 개인 프로젝트는 개인 사용·학습·개발 경험과 구현 결과를 설명한다. 실제 근거 없이 사업 성과·고객·매출·사용자 수를 붙이지 않는다.
6. 지원 직무 후보는 프론트엔드, React Native 모바일, 제품 개발 엔지니어다. 확정된 희망 직무·지역·연봉·근무 형태·입사 가능일은 아직 별도 확인이 필요하다. 기존 직책을 지원 직무명으로 바꾸지 않는다.

| 플랫폼 | 공식 사이트 | 로그인 진입 | 확인된 제공 방식 | 사용자 계정 방식 |
|---|---|---|---|---|
| 리멤버 | [rememberapp.co.kr](https://rememberapp.co.kr/) | [로그인](https://rememberapp.co.kr/login) | 앱·이메일, 공식 공개 검색 결과 기준 | Google 계정·2026-10-01 사용자 확인 |
| 원티드 | [wanted.co.kr](https://www.wanted.co.kr/) | 홈 로그인 버튼 → `id.wanted.co.kr` OneID | 카카오·Apple·Google·이메일, 공식 공개 검색 결과 기준 | Google 계정·2026-10-01 사용자 확인 |

| LinkedIn | [linkedin.com](https://www.linkedin.com/) | [로그인](https://www.linkedin.com/login) | 이메일/전화번호·비밀번호, Apple·패스키, 공식 공개 조회 기준 | Google 계정·2026-10-01 사용자 확인 |

위 표의 제공 방식은 공개 조회에서 확인한 일부 선택지이며 전체 목록을 의미하지 않는다. 네 플랫폼의 실제 계정 방식은 사용자 확인에 따라 기록했다. 실제 인증 절차를 직접 검증한 상태와 구분한다. 상세 출처·확인일·미확인 URL은 각 플랫폼 문서를 따른다.

### 공통 로그인 절차

1. 기존 탭·로그인 세션을 우선 사용한다. 문서 확인을 위해 로그아웃하지 않는다.
2. 세션이 만료되면 공식 사이트에서 로그인 화면으로 이동하고 기존 가입 수단을 사용한다.
3. 비밀번호 입력·소셜 계정 선택·앱 승인·패스키·OTP·CAPTCHA와 브라우저 권한 팝업은 사용자에게 넘긴다. 제어 반환 확인 후 같은 작업 공간에서 재개한다.
4. 로그인 후 본인 프로필과 기존 자료를 확인한다. URL 이동만으로 로그인 성공을 기록하지 않는다.
5. 로그인 수단명은 사용자 확인 후 플랫폼 운영 문서에 기록할 수 있다. 계정 식별 정보는 비공개 운영 기록에만 남긴다. 계정 이메일·전화번호·비밀번호·인증 코드·쿠키·토큰·일회성 인증 URL은 공개 문서나 Git에 보관하지 않는다.
6. 로그인 실패·계정 불일치·추가 인증은 남은 작업으로 기록한다. 새 계정 생성·로그인 방식 변경·계정 연동 해제는 별도 승인 범위에서 진행한다.

## 접근과 작업 순서

기본 접근 도구는 Ego Lite다. 연결된 공식 커넥터가 있고 작업을 지원하면 그 도구를 사용할 수 있다. 확인하지 않은 API나 고정된 화면 선택자에 의존하지 않는다.

1. 요청에서 대상 플랫폼, 읽기·문안 작성·저장·지원 중 승인 범위를 확인한다.
2. 기존 작업 공간과 해당 계정의 탭을 찾고 재사용한다. 계정·본인 프로필이 맞는지 확인한다. 비밀번호·인증 코드는 문서에 남기지 않는다.
3. 현재 화면과 저장된 내용을 먼저 읽고 기준 자료와의 차이를 정리한다. 입력 제한·저장 방식·공개 범위는 현재 화면에서 확인한다.
4. 해당 요청으로 승인된 수정만 반영한다. 기존 사용자 입력을 보존하고 미확인 필수 정보는 사용자에게 묻는다.
5. 저장 후 새로고침해 내용이 남아 있는지 확인한다. 긴 경력 문안의 누락·잘림, 첨부 파일·링크를 점검하고 실제 화면도 확인한다.
6. 결과는 작성됨 / 저장됨 / 화면 확인됨으로 구분한다. 실패·미확인은 남은 작업으로 기록한다.
7. 사용자가 브라우저 제어를 가져가면 멈춘다. 로그인·본인 인증이 필요하면 사용자에게 넘긴 뒤 같은 작업 공간에서 재개한다.

프로필 수정 승인은 지원서 제출, 제안 수락·거절, 메시지 발송, 인맥 요청, 공개 범위 변경까지 확대되지 않는다. 각 행동은 사용자가 승인한 범위에서 수행한다. 이미 승인된 동일 작업은 다시 묻지 않는다.

## 프로필 갱신과 지원 관리

- 새 경력·성과·프로젝트·사용자 정정이 생기면 기준 자료를 먼저 갱신하고 플랫폼별 반영 여부를 확인한다.
- 이력서 본문과 플랫폼 입력값이 다른 경우 플랫폼 값을 정본으로 가져오지 않는다. 사용자 확인과 근거를 확인한다.
- 공고는 회사명과 포지션, 공고 URL·ID, 마감일, 요구 역량을 확인한다. 같은 회사의 같은 포지션은 다른 플랫폼에도 올라왔는지 확인한다.
- 공고 적합성은 필수 역량, 확인된 경험, 미충족 조건, 근무 조건으로 설명한다. 근거 없는 합격 확률을 만들지 않는다.
- 제출 전 회사·직무·파일·문안·동의 항목을 확인한다. 제출 후 접수 완료 화면과 지원 현황으로 결과를 확인한다.
- 읽음·파일 업로드·버튼 클릭만으로 지원 완료를 기록하지 않는다. 플랫폼별 상태를 원문과 함께 보존한다.

### 비공개 운영 기록

실제 지원 현황·제안·연봉·담당자·대화·스크린샷은 Git 추적에서 제외된 `output/job-search/` 아래에만 보관한다. 이 안내 문서에는 계정 식별자와 실제 지원 내역을 쓰지 않는다.

프로필 변경 기록: 플랫폼 / 작업일 / 기준 자료 / 변경 항목 / 승인 범위 / 저장 여부 / 새로고침 확인 / 화면 확인 / 남은 일.

지원 기록: 회사 / 포지션 / 플랫폼 / 공고 URL·ID / 지원일 / 제출 자료 식별값 / 플랫폼 상태 원문 / 다음 행동·기한 / 중복 지원 여부.

## 점검 주기 제안

활동 수집은 매주 토요일, 사실·공개 범위의 공동 검토는 매월 초에 진행한다. 확정된 변경분의 반영과 채널별 버전·저장·게시 확인 기록은 [정기 이력 관리](../maintenance.md)를 따른다. 아래 제안·지원 현황 점검은 이력 갱신과 구분한다.

- 적극 구직 중: 주 1회 리멤버·원티드·그룹바이의 제안·공고·지원 현황을 확인한다.
- LinkedIn: 월 1회 프로필·주요 연락을 확인하고, 새 성과가 생겼을 때 내용을 갱신한다.
- 프로필 변경: 변경이 발생할 때마다 네 플랫폼의 반영 상태를 대조한다.

이는 운영 권장 주기다. 예약 작업·알림·자동 지원은 현재 설정하지 않는다.

## 승인된 수정의 최종 대조 (2026-10-02)

네 플랫폼의 저장된 경력 성과를 최신 원고와 대조해 28개 성과 문장의 누락이 없음을 확인했다. 네 회사 재직 기간, 네 전공, 자격증 취득월과 교육 활동 기간을 대조했다. LinkedIn의 남은 전공 표기를 정정한 뒤 재진입과 실제 화면을 확인했다.

최신 PDF 업로드는 그룹바이·LinkedIn에서 저장 후 확인했고 리멤버의 첨부 파일명도 확인했다. 원티드는 최신 기본 이력서와 최신 PDF만 유지하며, PDF 동일성은 앞선 다운로드 SHA-256 대조 기록을 따른다. 다른 플랫폼의 파일 내용을 새로 다운로드해 동일성을 검증한 것은 아니다. 원티드 프로젝트 날짜 12개는 사용자 확인에 따라 공란으로 유지했다. 그룹바이의 기존 프로젝트 수치·기여율은 사용자 요청으로 유지했으며 근거를 새로 검증한 것은 아니다.

이 검증은 승인된 프로필 수정 범위다. 추가 언어 프로필, 지원서 제출, 메시지·게시물, 희망 조건 변경은 포함하지 않는다. 그룹바이 프로필 공개는 해제, LinkedIn 이력서 공유는 해제 상태를 유지했다. 로그인된 기존 세션을 사용했으며 소셜 인증 자체는 새로 수행하지 않았다.
