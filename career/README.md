# 경력 자료 안내

이 디렉터리는 포트폴리오 웹, 이력서, LinkedIn, GitHub에 쓸 사실과 문안을 검토하는 작업 공간입니다. 원자료를 정리하고 개인 작업을 확인한 다음 채널별 표현을 작성합니다. 어느 채널에도 자동 반영되지 않습니다.

기간·역할·담당 프로젝트를 작성하기 전에 [경력·학력·자격증 기준 문서](facts/README.md)를 먼저 확인합니다. 사용자 정정이 과거 원본보다 우선합니다.

## 출처와 현재 상태

| 위치 | 용도 | 상태 |
|---|---|---|
| [경력·학력·자격증 기준](facts/README.md) | 회사별 기간·역할·작업 범위와 학력·자격증의 기준·미확인 사항 | 사용자 정정 우선, 변경 이력 보존 |

증빙 묶음의 Markdown에는 다른 저장소의 원래 위치를 가리키는 절대 경로 링크가 남아 있습니다. 이 파일들은 스냅샷 보존을 위해 수정하지 않았습니다. 해당 링크는 이 저장소에서 열리지 않을 수 있으므로 위 로컬 진입점과 `evidence/xenterra/fields/`, `evidence/xenterra/repositories/`를 이용하세요. 이 목록도 원자료의 모든 외부 링크가 유효함을 보장하지 않습니다.

## 작업 순서

1. 출처에서 작업 범위와 미확인 사항을 찾고, 개인이 직접 수행한 부분을 확인합니다. 계정·커밋 수를 성과나 기여율로 바꾸지 않습니다.
2. 역할, 기간, 결과 수치, 배포·운영 여부를 확인 가능한 근거와 대조합니다. 확인되지 않은 내용은 문안에 단정적으로 쓰지 않습니다.
3. 채널별 안내를 따라 초안을 작성하고 서로 사실관계를 대조합니다. 공개 가능한 정보만 남깁니다.
4. 웹 데이터, 이력서 PDF, 외부 프로필에 반영할 때는 각각 별도로 검토하고 수동으로 갱신합니다. 외부 게시는 명시적인 승인 후 진행합니다.

`evidence/`는 검토 전 자료를 포함할 수 있어 `.gitignore`로 제외했습니다. 공개할 내용이 정해지기 전에는 원문을 `public/`로 옮기지 마세요.
