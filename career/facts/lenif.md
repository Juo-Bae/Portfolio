## 확인 근거와 정정 사항

- 재직 기간은 최신 이력서의 월 단위 기록을 유지한다.
- 개발 부서·이사 직책과 개발팀 리딩은 사용자가 직접 확인한 내용이다. 확인 기록 (`../channels/resume/review-notes.md`, 로컬 전용·Git 추적 제외)의 「2026-09-29 레니프 개발팀 리딩 범위」 참조.
- 재직 중 개발팀 리딩을 맡아 IoT 제품 개발과 제조 협업·양산 적용을 진행했다.

## 현재 문안에 반영된 담당 프로젝트·작업 범위

아래 내용은 [최신 이력서 원고](../releases/resume/latest/resume.md)의 범위를 옮긴 것이다. 이 문서 작성만으로 새로운 사실 검증이나 기여율 확인이 이뤄진 것은 아니다.

#### 포즈빗(Posebit)

- React Native 앱에서 QR 스캔으로 기기를 식별하고, BLE 자동 연결과 Wi-Fi 프로비저닝으로 이어지는 연결 흐름 설계·구현
- 앱의 데이터·통계 조회 기능 개발
- ESP32 기반 회로 설계 및 RTOS 펌웨어 개발
- ToF 센서, 자이로스코프, BLE, Wi-Fi, AWS IoT Core MQTT, OTA 업데이트 연동 구현
- PCB 생산, 중국 제조 협업, 양산 적용 수행

#### 알람체어

- STM32, ToF 센서, 자이로스코프 기반 자세 교정 장치 개발
- RTOS 기반 착좌 판단, 자세 분류, 알람 로직 및 저전력 제어 로직 구현
- 회로 설계·펌웨어 개발·양산 수행, 외부 업체의 KC 인증을 위한 서류 준비

## 확대하지 않을 표현·미확인 사항

- 팀 규모, 인사 권한, 리딩 기간의 세부 일자는 미확인이다.
- KC 인증은 외부 업체의 인증을 위한 서류 준비 범위다. 인증 전체를 직접 수행한 것으로 확대하지 않는다.
- 펀딩 결과나 제품 판매를 개인의 성과 수치로 연결하려면 담당 범위와 별도 근거를 확인한다.

## 적용 규칙

- 이 문서의 사실과 표현 범위는 이력서·PDF·포트폴리오·외부 프로필의 공통 기준이다. 길이와 순서는 채널별로 달라도 날짜와 기여 범위를 확대하지 않는다.
- 사용자 정정 없이 과거 자료에서 날짜나 역할을 가져와 덮어쓰지 않는다. 새로운 확인이 있으면 근거와 변경 이력을 남긴 뒤 관련 채널을 대조한다.
- 월 단위 기간으로 정확한 입퇴사일을 추정하지 않는다. 프로젝트 수행 기간은 재직 기간과 구분한다.
- 성능 수치·개인 기여율·단독 구현·운영 효과는 별도 근거가 있을 때만 추가한다.
- 경력 기준과 정정 기록은 보존한다. 이전 이력서 파일은 2026-10-01 사용자 요청으로 삭제했다. 이 문서는 공개 자산이 아니며 외부 게시는 별도 승인 범위에서 진행한다.

## 변경 이력

- 2026-10-01: 회사별 기준 문서 생성. 이후 변경은 근거와 수정 사유를 이 절에 기록.
- 2026-10-01: 사용자 승인으로 웹 성과 문장을 구체적인 앱 기능·회로·펌웨어·양산 기여로 정리. 펀딩·출시 완료 표현을 개인 성과에서 제외하고 참고 링크는 유지. 재직 기간과 기존 작업 사실은 변경하지 않음.
