## 확인 근거와 정정 사항

- 재직 기간은 최신 이력서와 기존 종료월 정정 내용을 유지한다. 종료월을 `현재`로 되돌리지 않는다.
- 직무 설명은 현재 웹 경력의 표현이다. 공식 직급이나 직책을 추가하지 않는다.

## 현재 문안에 반영된 담당 프로젝트·작업 범위

아래 내용은 [최신 이력서 원고](../releases/resume/latest/resume.md)의 범위를 옮긴 것이다. 이 문서 작성만으로 새로운 사실 검증이나 기여율 확인이 이뤄진 것은 아니다.

#### 3D 아바타 렌더링

- 기존 2D 영상 자산 의존 구조를 3D 모델 렌더링 구조로 전환
- Bare React Native 환경에서 Expo GL, Three.js를 연동해 씬 구성, 모델 로딩, 애니메이션 제어 구현

#### 음성 채팅 인터랙션

- WebSocket 기반 음성 송수신·재생 흐름에 캐릭터의 연결·발화·응답 상태 전환을 연동
- 소켓 연결·송수신 처리와 영상·녹음·재생 로직을 분리하고 관련 테스트 코드 작성

#### 모바일 배포 자동화

- fastlane으로 iOS·Android 네이티브 빌드·업로드, EAS Update로 OTA 배포 운영
- 런타임 버전 변경 여부에 따라 네이티브 빌드와 OTA 배포를 분기하고, 플랫폼 선택·Git 태그·Slack 알림을 스크립트로 연결

#### CES 2026 제품 시연

- 전시 부스에서 제품을 시연하고 방문자 응대·제품 소개 진행

## 확대하지 않을 표현·미확인 사항

- 영상의 seek·구간 반복 세부 구현과 전체 음성 엔진·프로토콜의 단독 설계는 확인된 범위로 단정하지 않는다.
- 3D 전환의 렌더링 성능·메모리 개선 수치, 배포 시간 절감률은 미확인이다.
- CES 2026 경험은 제품 시연·방문자 응대·제품 소개다. 행사 참가 성과를 매출로 확대하지 않는다.

## 적용 규칙

- 이 문서의 사실과 표현 범위는 이력서·PDF·포트폴리오·외부 프로필의 공통 기준이다. 길이와 순서는 채널별로 달라도 날짜와 기여 범위를 확대하지 않는다.
- 사용자 정정 없이 과거 자료에서 날짜나 역할을 가져와 덮어쓰지 않는다. 새로운 확인이 있으면 근거와 변경 이력을 남긴 뒤 관련 채널을 대조한다.
- 월 단위 기간으로 정확한 입퇴사일을 추정하지 않는다. 프로젝트 수행 기간은 재직 기간과 구분한다.
- 성능 수치·개인 기여율·단독 구현·운영 효과는 별도 근거가 있을 때만 추가한다.
- 경력 기준과 정정 기록은 보존한다. 이전 이력서 파일은 2026-10-01 사용자 요청으로 삭제했다. 이 문서는 공개 자산이 아니며 외부 게시는 별도 승인 범위에서 진행한다.
