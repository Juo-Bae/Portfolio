## 확인 근거와 정정 사항

- 입사월과 개발 부서·차장 직책은 최신 이력서의 기록을 유지한다.
- `재직 중`은 2026-10-01 기준 상태다. 종료월은 고정하지 않고 이후 사용자 확인에 따라 갱신한다.
- 개인 수행·현업 적용은 사용자 진술과 기여 범위 검토 기록 (`../channels/resume/review-notes.md`, 로컬 전용·Git 추적 제외)을 함께 해석한다. 커밋 작성자나 AI 생성 기록만으로 개인 기여율을 확정하지 않는다.

## 현재 문안에 반영된 담당 프로젝트·작업 범위

아래 내용은 [최신 이력서 원고](../releases/resume/latest/resume.md)의 범위를 옮긴 것이다. 이 문서 작성만으로 새로운 사실 검증이나 기여율 확인이 이뤄진 것은 아니다.

#### 모바일·웹 메신저 및 음성 통화 개선

- 모바일 메시지·채널 목록과 웹 메시지 버블을 분리·메모이제이션해 상태 변경 시 다시 그리는 항목의 범위 축소
- 웹 채팅방 표시 때 자동 발생하던 첨부 원본 URL 요청을 열기·다운로드 시점으로 옮기고, URL 일괄 조회·파일 캐시 적용
- 앱의 포그라운드·백그라운드 수신과 시스템 통화 화면을 공통 세션에 연결하고 통화 상태·중복 이벤트 처리 보완

#### 물류·AS 업무 시스템 기획·개발

- 물류 담당자 인터뷰로 업무 흐름을 정리하고, 화면·기능 기획부터 구현·업무 적용까지 주도
- 외부 운송 정보 API를 연동해 해상 운송의 위치·경로·진행 상태를 지도와 상세 화면에 시각화하고 현업 피드백 반영
- AS 담당자 인터뷰를 바탕으로 접수·상태 이월·일정 배정 화면을 기획·구현

#### 구매발주 화면·자재 데이터 조회 구조 개선

- 핵심 업무 우선 로딩과 탭별 지연 조회로 구매발주 화면의 데이터 로딩 구조 재구성
- 제품·자재 연결을 사전 계산해 저장하는 매핑 생성·갱신 경로를 구현하고, 자재 현황의 완제품 연결 조회에 적용

#### 생산 현장 작업자 도면 시스템 개선

- 기존 도면 시스템의 데이터 업로드·편집과 레이아웃 관리 화면을 보완하고, 품번·설계 옵션에 맞춘 작업자 표시 흐름 검증
- 외부 인터넷 접근이 제한된 작업자 PC를 위해 현장 중계 서버에 화면을 제공하고, 도면·이미지 조회를 동일 출처의 읽기 전용 경로로 분리

#### 개발문서 정리 및 변경 영향 검사 자동화

- 코드 변경 파일을 도메인별 개발문서와 매핑하고, 관련 문서 갱신 누락을 검사하는 스크립트·hook 추가

## 확대하지 않을 표현·미확인 사항

- 메신저·통화는 기존 기능 개선이다. 전체 시스템 신규 구축·단독 소유·실기기 운영 성공률을 주장하지 않는다.
- 제품·자재 매핑은 자재 현황의 완제품 연결 조회에 적용한 범위다. 구매발주 전체의 BOM 역산을 제거했다고 쓰지 않는다.
- 작업자 도면은 중계 경로와 읽기 전용 조회 분리다. 완전 오프라인 운영이나 현장 성능 개선 수치를 주장하지 않는다.
- 개발문서 검사·hook은 갱신 누락 확인 경로다. 문서 정확성 보장·전사 강제 적용을 뜻하지 않는다.
- AI 도구 활용은 현업 요구 구체화·변경 검토·통합·검증 경험으로 설명한다. 세션 수나 직접 코드 작성 비율을 추정하지 않는다.

- 이 문서의 사실과 표현 범위는 이력서·PDF·포트폴리오·외부 프로필의 공통 기준이다. 길이와 순서는 채널별로 달라도 날짜와 기여 범위를 확대하지 않는다.
- 사용자 정정 없이 과거 자료에서 날짜나 역할을 가져와 덮어쓰지 않는다. 새로운 확인이 있으면 근거와 변경 이력을 남긴 뒤 관련 채널을 대조한다.

- 성능 수치·개인 기여율·단독 구현·운영 효과는 별도 근거가 있을 때만 추가한다.
