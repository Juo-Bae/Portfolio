## 학력·자격증

- [학력 기준](education.md): 학교·기간·졸업 상태·전공
- [자격증 기준](certifications.md): 명칭·취득월·기존 기관 표기와 확인 범위

## 우선순위

1. 사용자의 명시적 확인·정정과 그 근거를 기록한 회사별 기준 문서.
2. 해당 문서의 미확인 표시와 검토 기록 (`../channels/resume/review-notes.md`, 로컬 전용·Git 추적 제외).
3. 채널별 문안과 최신 산출물.
4. 원본·과거 릴리스. 정정 전 내용이 있으면 현재 사실의 기준으로 복원하지 않는다.

기간을 합치기 전에 실제 재직 여부를 확인한다. 이름과 기간의 연속성만으로 오기 항목을 합치지 않는다. 회사 재직 기간과 개별 프로젝트 수행 기간은 구분한다.

## 고정 사실과 파생 정보

- 확정된 입퇴사 기간·과거 역할·확인된 작업은 사용자 정정이나 새 근거 없이 바꾸지 않는다.
- 젠테라의 현재 재직 상태, 총 경력 개월 수, 소개 문구는 시간에 따라 갱신되는 파생 정보다.
- 현재 소개는 `7년 이상`이다. 원본 오류에서 파생된 `8년 6개월`을 복원하지 않는다. 정밀한 합계가 필요하면 계산 기준일과 월 산정 방식을 명시한다.
- 문안에 등장한다는 이유만으로 검증 완료를 뜻하지 않는다. 각 회사 문서에 기록한 근거와 미확인 범위를 유지한다.

## 갱신 절차

1. 사용자 확인이나 새 근거를 해당 회사 문서에 기록하고 변경 이력을 남긴다.
2. [작업 원고](../channels/resume/resume-draft.md), [최신 원고](../releases/resume/latest/resume.md), 최신 PDF, [웹 데이터](../../src/portfolioData.js), 웹 다운로드 PDF를 대조한다.
3. 원본과 과거 릴리스는 보존한다. 외부 게시·배포는 별도 승인 범위에서 진행한다.

이 문서는 로컬 관리 문서이며 공개 파일을 자동 생성하는 기능은 없다.
