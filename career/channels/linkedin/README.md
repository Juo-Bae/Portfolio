# LinkedIn 문안

이 폴더는 LinkedIn 소개와 경력 항목의 초안을 정리하는 공간입니다. 현재는 안내만 있으며 LinkedIn 프로필을 자동 수정하지 않습니다.

1. [경력 자료 안내](../../README.md)의 원자료에서 개인 역할과 확인된 사실을 찾습니다.
2. 소개·경력 항목에 맞게 짧게 쓰되 기간, 직책, 성과를 근거 없이 확장하지 않습니다.
3. 이력서·웹·GitHub 문안과 사실관계 및 비공개 정보 포함 여부를 대조합니다.
4. 게시할 문안을 검토한 뒤 별도 승인 범위에서 LinkedIn에 수동 반영합니다.
