# 이력서 문안

이 폴더는 이력서에 넣을 경력 문장과 확인 사항을 정리하는 작업 공간입니다. 최신 로컬 제출용 확정본은 별도 릴리스 경로에 보관합니다. 외부 게시 상태를 뜻하지 않습니다.

- [회사별 경력 기준](../../facts/README.md)
- [최신 제출용 PDF](../../releases/resume/latest/soonho-bae-resume.pdf)
- [최신 이력서 문안](../../releases/resume/latest/resume.md)
- [릴리스 이력](../../releases/resume/README.md)
- [수정 작업용 문안](resume-draft.md)
- 기여 범위·근거·남은 확인 사항 (`review-notes.md`, 로컬 전용·Git 추적 제외)

1. [경력 자료 안내](../../README.md)에서 출처와 미확인 사항을 확인합니다.
2. 각 문장에 개인 역할·작업 범위·기간·결과의 근거를 연결하고, 확인 전 수치나 성과는 보류합니다.
3. 공개 가능한 표현으로 다듬고 다른 채널과 사실관계를 대조합니다.
4. 검토를 마친 뒤 이력서 파일과 웹의 PDF를 각각 수동으로 갱신합니다. `public/media/resume.pdf`가 현재 웹에서 연결되는 공개 자산입니다.
