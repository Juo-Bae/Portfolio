# GitHub 프로필 문안

이 폴더는 GitHub 프로필 소개와 공개 프로젝트 설명의 초안을 정리하는 공간입니다. 현재는 안내만 있으며 GitHub 프로필이나 저장소를 자동 수정하지 않습니다.

1. [경력 자료 안내](../../README.md)와 공개 가능한 저장소·근거를 확인합니다.
2. 프로젝트별 개인 기여와 팀·프로젝트 전체 배경을 구분해 설명합니다. 비공개 저장소의 코드·내부 링크·원자료를 공개 문안에 복사하지 않습니다.
3. 이력서·LinkedIn·웹 문안과 사실관계를 대조하고 링크 공개 가능 여부를 확인합니다.
4. 게시할 문안을 검토한 뒤 별도 승인 범위에서 GitHub에 수동 반영합니다.
